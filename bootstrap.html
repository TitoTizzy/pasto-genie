Setup Supabase

Cette page remplace l'ancien demarrage. Configurez les cles dans js/supabase-config.js, puis creez les tables et les politiques RLS dans Supabase.

Configuration client

const supabaseUrl = "https://YOUR_PROJECT_REF.supabase.co";
const supabaseAnonKey = "YOUR_SUPABASE_ANON_KEY";

Compte superadmin

Creez un utilisateur dans Supabase Auth, puis ajoutez une ligne dans la table users avec le meme identifiant.

insert into public.users (id, email, display_name, role)
values ('AUTH_USER_ID', 'admin@example.com', 'Administrateur', 'superadmin');
